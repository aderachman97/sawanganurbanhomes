# Sawangan Urban Homes - Landing Page

Official landing page website for **Sawangan Urban Homes** by **Nufist Realty**.

- **Lokasi:** Jl. H. Jawi, Sawangan, Kota Depok, Jawa Barat
- **Produk:** Rumah Modern 2 Lantai (Tipe 65/66) & Kavling Siap Bangun SHM 66m²
- **Hotline:** 0819 1159 0700 / 0812 8279 3135

## Tech Stack
- HTML5 (Mobile-First Architecture)
- Tailwind CSS (Modern Utility Styles)
- Lucide Icons (Vector Graphics)
- Interactive Vanilla JavaScript:
  - Dual Mode KPR Calculator (Syariah Flat vs Konvensional)
  - Interactive Before/After Sliders
  - Interactive 2D Blueprint Floor Plan (Lantai 1 & 2)
  - Interactive 13-Unit Site Plan Grid
  - Slot Picker Survey Modal
  - Floating WhatsApp Widget
  - Exit-Intent Modal
  - Social Proof Activity Toasts

## Branches
- `main`: Production release
- `staging`: Development & preview testing
